# BiteLedger

A privacy-first food tracking app for iOS.

## Features

- 📱 Barcode scanning (always free)
- 🔒 All data stays on your device
- 📈 7-day rolling average history chart
- 📤 Weekly recap share card
- ⚡ Quick-Add recent/frequent foods per meal type
- 🔥 Streak milestone celebrations (3, 7, 14, 30, 60, 100 days)
- 🎯 No account required
- 💪 Comprehensive nutrition tracking

## Tech Stack

- SwiftUI
- SwiftData
- HealthKit
- Open Food Facts API
- iOS 26.0+

## Privacy

BiteLedger never sends your data to our servers. Everything is stored locally using SwiftData, with optional sync to Apple Health.

## Development

Built with Xcode 16.3 and Swift 6.0
